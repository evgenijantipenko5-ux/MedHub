# MedHub

Кабинет обучения для Слуцкого медицинского колледжа. Лечебное дело, 2 курс.

## Предметы

| Предмет | Что внутри | Вопросов |
|---------|-----------|----------|
| 🫀 Анатомия | Лекция 1 — Введение (плоскости, оси, номенклатура). Лекция 2 — Клетка: строение, функции, деление. Лекция 3 — Ткани: эпителиальная ткань. Лекция 4 — Соединительная ткань | 95 |
| 💊 Фармакология | Лекции 1–2 — Введение, общая рецептура, твёрдые лекарственные формы | 23 |
| 🩺 СДМТ | Лекция 1 — Введение. История развития сестринского дела | 12 |
| 🦠 Микробиология | Лекция 1 — Инфекция, инфекционный процесс и иммунитет | 12 |

## Как запустить

Просто открой `index.html` в браузере. Всё работает без сервера и интернета.

## Структура

```
MedHub/
├── index.html          # Главная страница (хаб)
├── style.css           # Общие стили
├── AnatomyApp/         # Анатомия (лекции + интерактив)
├── PharmacologyApp/    # Фармакология
├── SdmApp/             # СДМТ
└── MicrobiologyApp/    # Микробиология
```

## Технологии

Vanilla HTML + CSS + JavaScript. Без фреймворков и зависимостей. Интерактивные SVG-диаграммы, вкладки, квизы с проверкой ответов.
